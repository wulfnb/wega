A Native Rust Browser
Powered by Servo

Wega is an independent desktop browser engineered in Germany that embeds the open-source Servo 0.7.0 engine. Built with movable tabs, AppKit vibrancy, and zero unsafe code in its core.

Quick Launch via Docker
docker run -d \
  --name wega-browser \
  -p 127.0.0.1:7443:7443 \
  -e BROWSER_USER=servo \
  -e BROWSER_PASSWORD='choose-a-strong-password' \
  -v wega-profile:/config \
  ghcr.io/wulfnb/wega:latest

# Open https://localhost:7443 and sign in as servo with your chosen password.
# Never expose port 7443 to the internet; use Tailscale/WireGuard or a trusted reverse proxy.

Why Wega?

Born out of the frustration with RAM-heavy corporate browsers and the dream of turning Servo into a daily driver.

🚀

A Real Servo Browser

For years, the revolutionary Servo engine existed primarily as an embedded research library. Wega brings it to life as a complete, usable browser with draggable tabs, bookmarks, and developer tools.

🏠

Built for the Homelab

Access your internal home server dashboards and the wider web over secure, authenticated HTTPS with zero heavy desktop bloat. Deploy in seconds via lightweight Docker containers.

🍃

Ending RAM Exhaustion

No more system freezes or fan noise from dozens of hidden browser helper processes. Built in Rust with immediate-mode UI for predictable, minimal memory consumption.

🌐

Breaking the Monoculture

With almost every browser now running on Google's Blink/Chromium engine, web standards risk being dictated by a single advertising giant. Wega keeps the open web diverse by championing Servo.

🔒

Radical Privacy & Zero Telemetry

No tracking IDs, no diagnostic phone-home telemetry, and no ad profiling. Your navigation, credentials, and session state remain strictly local to your machine.

🛡️

Rust-First Memory Safety

Many browser exploits trace back to C/C++ memory corruption. Wega's own code is Rust, its core library forbids unsafe, and the desktop app keeps a few small, reviewed unsafe blocks. The engine still includes SpiderMonkey (C++ with a JIT) and GStreamer and runs in one process by default, so memory safety is not end-to-end.

Built for Performance and Modularity

Wega strictly separates presentation, session transitions, and engine handles through Hexagonal Ports & Adapters.

⚡

Servo 0.7.0 WebRender

Websites are fetched, parsed, and painted via Servo's multi-threaded WebRender GPU pipeline. Each tab renders into an isolated offscreen framebuffer composited via OpenGL.

📐

Movable Draggable Tabs

Tabs can be placed in a top horizontal strip or a resizable vertical sidebar with fluid drag-and-drop reordering that keeps live WebViews and engine states intact.

🛡️

Zero Unsafe in Core

The core business domain enforces #![forbid(unsafe_code)]. Storage durability, URL validation, and session models compile and test without any window server or GPU.

🍎

Native AppKit Integration

Under macOS, Wega embeds native NSVisualEffectView vibrancy behind the render layer, bridges Control Center media keys, and connects with UNUserNotificationCenter.

⬇️

Multipart Streaming Downloads

Parallel segmented downloading via process-isolated streaming workers. Features automatic range detection, atomic publication, and collision-resistant file placement.

🛠️

10 Native DevTools Panels

Built-in developer tools including DOM Tree Inspector, Live CSS Style Editor, Network HAR Recorder, Storage & Cookie Viewer, and Getter-Safe Console Evaluator.
